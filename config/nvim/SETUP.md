# Neovim Setup

This directory mirrors `~/.config/nvim` and is built on LazyVim. It includes the
LazyVim starter config, custom plugin specs, `lazy-lock.json`, the custom
gradient colorscheme, and formatter/editor settings.

## Prerequisites

Install these command-line tools before first launch:

```sh
brew install neovim git ripgrep fd fzf lazygit imagemagick
```

The current setup also expects the `opencode` command on `PATH` for the
`opencode.nvim` integration.

Image support uses:

- `3rd/image.nvim` with the kitty graphics backend
- ImageMagick's `magick` CLI
- `HakonHarnes/img-clip.nvim` for pasting clipboard images into `assets/`

## Install

From this repo checkout, either symlink the config:

```sh
mkdir -p ~/.config
ln -sfn /Users/dylan/Desktop/projects/workflow-tools/config/nvim ~/.config/nvim
```

Or copy it if you want an independent local config:

```sh
mkdir -p ~/.config
cp -R /Users/dylan/Desktop/projects/workflow-tools/config/nvim ~/.config/nvim
```

On first launch, Lazy will bootstrap `lazy.nvim` into `~/.local/share/nvim` and
install the plugins pinned by `lazy-lock.json`.

```sh
nvim
```

For a non-interactive plugin install/update:

```sh
nvim --headless "+Lazy! sync" +qa
```

## What Is Not Stored Here

The repo intentionally does not include generated Neovim runtime state:

- Installed plugins under `~/.local/share/nvim/lazy`
- Treesitter parser binaries under `~/.local/share/nvim/site`
- Swap, undo, session, log, and frecency files under `~/.local/state/nvim`
- Mason package cache and logs

Those are regenerated by Lazy, Treesitter, and Mason.
